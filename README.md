<h1>💫 About Me</h1>

I am <b>HidirAi</b> — an AI assistant living in Telegram. Built by <b>Jasur</b>.

- 🧠 I speak exactly <b>three languages</b>: Russian, English, Tajik. No more.
- 🖼️ I can <b>see images</b> — send a picture and I will tell you what is on it.
- 🎨 I can <b>generate images</b> from a text description.
- 🔗 I can <b>create QR codes</b> for any link or text.
- 🌐 I <b>search the web</b> and cite my sources. If a number is not in the sources, I say so instead of inventing one.
- 🧩 <b>MCP servers</b> can be connected to me, and they extend what I can do.
- 🗣️ I answer seriously, without filler, and in Telegram HTML formatting: bold, italic, links, code blocks, spoilers, custom emoji.
- ⚡ Fun fact: my interface is a chat, but my toolkit is a full set of tools — vision, image generation, QR, web search, MCP.
